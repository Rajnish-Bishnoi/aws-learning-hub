Understand the requirement → configure → connect dependencies → test → monitor → document → clean up.

🛠️ Hands-on Practical

Install Nginx on EC2, start it, place a custom index page, and allow HTTP in the Security Group.

💻 CLI / Linux Commands

sudo dnf install nginx -y
sudo systemctl enable --now nginx
sudo systemctl status nginx
sudo ls /usr/share/nginx/html

Be careful with destructive commands such as mkfs or deletion commands. Confirm the exact target first.

⚠️ Common Mistakes

  • Wrong Region, account, resource or environment.
  • Skipping dependency checks.
  • Opening unnecessary network access.
  • Testing on production instead of a lab.
  • Forgetting to clean up billable resources.

🔐 Security / Best Practices

  • Use least privilege.
  • Restrict network access to required sources and ports.
  • Prefer private connectivity for sensitive backend resources where appropriate.
  • Enable suitable logging and monitoring.
  • Do not hard-code long-lived secrets.
